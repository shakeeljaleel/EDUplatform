# Anti-Gravity Autonomous Coding Rules

These instructions must be checked before making any code modifications in EDUPLATFORM:

1. **Pre-commit Build Check**: Always run `npm run type-check`, `npm run lint`, and `npm run ui-check` locally before submitting code changes.
2. **UI Consistency Enforcement**:
   - Check `COMPONENT-STANDARDS.md` before adding or modifying any button, card, or page layout.
   - Never use gradient fills on buttons or cards.
   - Never use ALL CAPS in button or label text literals.
   - Never place greeting headers on inner sub-pages.
3. **Information Architecture Integrity**:
   - Keep Branches and Batches decoupled: Branches page manages physical/online branches; Batches page manages intakes and full-width tables.
   - Every batch form MUST contain a Branch dropdown selection.
4. **Git Branching Policy**:
   - Commit all developed work to `develop`.
   - Merge `develop` into `main` only after all quality gate checks (`type-check`, `lint`, `ui-check`, `build`) pass cleanly with zero errors.
